Student Management System

A web-based Student Management System developed as part of a college group project using PHP, MySQL and Bootstrap 5.

My Contribution

As a team member, I contributed to the development of the Student Management System, with a focus on implementing the **Live Classroom Question & Answer feature**.

### Live Classroom Q&A Feature
- Developed a feature that allows students to ask questions during classroom sessions.
- Enabled teachers to view and respond to students' questions.
- Helped facilitate interactive communication between students and teachers.
- Contributed to making classroom interactions more engaging through the web application.
